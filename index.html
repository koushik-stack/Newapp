My Own Programming Language (The Retro-Father)

2022

  • Lexing & Tokenization
  • Syntactic Analysis
  • Parsing
  • Compiler & Interpreter Design

As a personal and academic challenge, I designed and implemented Retro-Father, my own programming language. It consists of a recursive descent parser that performs lexical analysis and builds an abstract syntax tree (AST), and an interpreter that traverses the AST to execute programs. Even in its early form Retro-Father supports lambda expressions, closures, and first-class pure functions, providing a strong foundation for functional programming. Planned enhancements include multithreading, a stronger type system, tail-call optimization, and a stack-based virtual machine for executing bytecode with greater efficiency.

Acting as an automatic compiler, it enables rapid, optimized GPU execution, bridging the gap between Python development and efficient parallel computation.
