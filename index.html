My Own Programming Language (The Retro-Father)

2022

  • Lexing & Tokenization
  • Syntactic Analysis
  • Parsing
  • Compiler & Interpreter Design

In 2022, as a personal and academic challenge, I set out to design my own programming language, which I later called Retro-Father. The language is built around two core components: a recursive descent parser, which performs lexical analysis and tokenization to construct an abstract syntax tree (AST); and an interpreter, which traverses the AST to evaluate and execute the intended behavior.

Even in its early form, Retro-Father supports some powerful features: lambda expressions, closures, and first-class pure functions, making it a solid base for functional programming. Looking ahead, I’m planning to add multithreading, a stronger type system, and performance features like tail-call optimization. I’ve also started experimenting with a stack-based virtual machine that executes bytecode, aiming to push execution efficiency even further.
