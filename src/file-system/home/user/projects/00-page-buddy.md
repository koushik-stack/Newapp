



## *PLAY*
## 2019

### • React, JavaScript, Sql, Software
### • Originally built as a Bootstrap-based software prototype, Play was an early experiment combining neural networks with developer tooling. Its primary goal was to help developers integrate our API directly into any code editor, enabling seamless interaction and enhanced automation. This project laid the foundation for smart editor extensions and focused on making AI-assisted development both accessible and plug-and-play across tech stacks.
